# 终章 上条当麻

> Notice_of_the_Death.

社会的齿轮，构造得还真是精巧。

即便在这般异常的事态之中，也能迅速将患者从扭曲的中心转移出来，搜索最短路线送往最近的医院。早已建立起了这样的机制。

是一辆救护车。

少女们踩得咚咚作响，从后车门冲进了同一辆车里。

&nbsp;

『蠢货！该死，心脏完全停跳了……！！』

『那又如何。让心脏重新跳动的方法多的是。倒是幸亏我们恰好在附近，让救护车在地面上跑迟早会被暴徒堵住。虽说核心的爱丽丝·异典已经安静下来了，不过已经涌上街头的群众们不可能一秒钟就全都回家！』

『……我们去把他们打倒？』

『你这坏女人别在那瞎起劲，给我面对现实。感情用事只是浪费时间。比起这个，喂，救护车上应该有车载无线电吧。把那玩意叫来。别说学园都市没有！！』

&nbsp;

虽然街道到处都挤满了暴徒，无法正常通行，但陷入困境的救护车仍能用无线电发出求援信号。不管大街上挤满了多少人，都阻挡不了空中飞行的急救直升机。

在一处较为开阔的公园里转运担架。

少年被粗大的安全带牢牢固定，一句话也没说。

他就像一件普通的行李，

一个物体。

&nbsp;

『紧急救援请求，一名十几岁的男性，情况为DOA！伤势如何？不知道，真的不知道。我在现场转了二十年，都无法想象他是怎么受的这些伤！！』[^1]

『总之先把照片和数据全部传给医院那边吧，这样最快！！』

&nbsp;

急救人员的吼声毫不留情。

即便是某种意义上的专业人士，

恐怕连顾及同在机舱内的亲近之人的余力都没有吧。

&nbsp;

『我们已经晚了几分钟，该死。封闭伤口，别让他体温下降。把人送到医生面前，是我们的工作。』

『但是这已经……实在是……』

『闭嘴！！除非有执照的医生正式确认死亡，在那之前他都还是病人。我不知道你到底为什么转行过来，但没有资格的人，不要擅自放弃别人的生命！！』

&nbsp;

&nbsp;

&nbsp;

医疗直升机通过无线电联络，朝着附近医院的停机坪飞去。

降落过程十分谨慎，堪称完美。

机体后部的进出舱门向两侧大大敞开。

「哐当哐当」生硬而沉重的金属声越来越响。

分不清究竟是在卸下人，还是医疗设备。

感觉就像是把所有能连上的仪器、电线、装有液体的袋子和管子，全都一股脑接到了担架上。

在学园都市，虽说尚未正式公开，但连改造人技术都已经投入实用了。

极端地说，内脏什么的并非必需品。如果有外置固定型的生命维持装置，无需为了收纳进体内而在保持性能的同时把尺寸彻底缩小，老实说，人体的相当一部分功能都能够补足。如今这个时代，就算原生的内脏损毁了几个，也照样能维系人的生命。至于在体内还是体外，并不重要。呼吸也好，脉搏也罢，血压也好，脑电波也罢，从医学角度来说，「生命」不过是一种状态。摄取、生产、运输、消耗、排泄，总之只要维持住这一个循环，生物学意义上，人就能继续活下去。

只要想象一个仅由干电池和小灯泡构成的简单电路即可。

如果切断构成回路的电线，灯泡就会熄灭。

稳定的状态就会消失。

但如果并联接入两节电池，即使切断其中一根电线，灯泡也能继续发光。

无论破坏的结果如何，状态都会保持不变。

这个道理放到电生理学、分子生物学、血液学等极其复杂、高深的生物学领域，也是一样的。

不过，从太古时代就存在的所谓「灵魂」，只要有了最尖端的科技，就能被**欺骗**。

这里的「欺骗」，就像魔术师或食品模型师常说的那样。

是为了取悦所有人而精心设计的幸福巧思。

&nbsp;

**但即便如此**。

&nbsp;

有着如此高超的技术，

少年的身体却没有发出一点声响。

这已经不是那种程度的问题了。

少年的刘海只是任凭寒冷的夜风随意摆弄。

仿佛路边的杂草或是别的什么，从中感受不到丝毫意志。

比完全不动更加残酷。

比复印纸还薄的特殊监视器上，只有一条平直的横线。数字是0，单调的电子音无休无止地持续着。

仅此而已。

所有人都在聆听着那无情的单音。

除了急救团队和医生，不知为何还有一些无关的平民，出现在这危险的屋顶上。

&nbsp;

『呀？！』

&nbsp;

传来一声微弱的尖叫，是御坂美琴发出的。

那个被留下的少女。

被保留下来的战力。

似乎背负着一种宿命，永远与那个少年最为接近，却又注定无法触及决定性的结局。

停机坪上还有另一个少女。

一头蜂蜜色的长发在直升机的气流中飞舞。

那名背负着与美琴不同宿命的少女说道：

&nbsp;

『所以，我早就告诉过你啊。如果一直这样下去，总有一天会落得这样的下场……』

&nbsp;

&nbsp;

&nbsp;

声音渐渐远去。

围在担架旁的人们你一言我一语地大声争吵着，匆匆从屋顶赶到医院内部。目的地或许是手术室，或许是重症监护室。

他们是还没放弃吗？

是还不愿承认吗？

是因为一旦停下脚步就会有所察觉，从而自己对自己心生恐惧吗？

一切无声。

不久之后。

即便如此。

和上条当麻同乘一架救护直升机的茵蒂克丝，却没能走下机舱。

她动弹不得。

只是用双手捂住嘴巴。

纯真少女的眼角渐渐浮现出透明的泪珠。她用双手遮住整张脸。

砸下来的是黑暗。

是离别的象征。

是死亡。

&nbsp;

『……』

&nbsp;

她说不出话来。

完全记忆能力，在这种时候，对她而言是一种残酷的才能，还是一种永远留住那个少年的安慰呢，哪怕只是在脑海中。

&nbsp;

&nbsp;

&nbsp;

过了一会儿。

最后，长着青蛙脸的医生缓缓摇了摇头。

『……一月六日，晚上十一时五十八分。』

横向地。

已经说明了一切。

这位从不轻言放弃的医生，唯独这一次，却还是说了出来。

&nbsp;

『送来的病人已经确认死亡。对已经死去的人，我们真的无能为力。』

上条当麻。

没能迎来作为寒假最后一天的一月七日，他的死亡很快就得到了确认。

[^1]: 译注：即Dead on arrival，意为送达时已经死亡。
