## 内容简介

**寒假的最后一天，失去了生命的上条当麻，醒来的地方是——**

上条当麻为了拯救爱丽丝，坚持到了最后。

但是，他的生命之火已经完全消散……生命活动停息了。

寒假的最后一天。学园都市的某个少年被确认死亡。

随后。

虚无。空无一物的空间。上条醒来之处，是他一直以来打消的『幻想』本身——这里有一名女性，安娜·金斯福德。但是为什么会来到这里？上条惊讶着，听到了一个提案。等等，『这种事情』真的办得到吗……？
