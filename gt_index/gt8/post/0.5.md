# 行间一

第十二学区，「桥架结社」领事馆。

时间停滞了。

爱丽丝·异典换上了一身妖异的皮衣，柔嫩的肌肤暴露在一月的呼啸寒风中。她茫然地盯着某一点，似乎对外面的世界不感兴趣。

尽管超绝者人数众多，却都踌躇不前，无一人敢上前搭话。

所有人都深知，稍有失言，就足以让区区「普通」的超绝者粉身碎骨。

「啊」

所以，H.T.特利斯墨吉斯忒斯这番举动绝非疏忽大意。

为夺回尊敬的主人的时间，就算粉身碎骨也在所不辞。这应是他作为青年执事的忠义之举。

「爱丽、丝……？」

有一阵沉默，静得让人耳朵发痛。

紧张感暗藏其中。

凡是「桥架结社」的超绝者，都将爱丽丝·异典的心情胜过整个世界这一点深深地铭记进了骨髓里。因此任何人都会这么想，这是个地雷，稍有不慎，三步之内就会引发毁灭性的风暴。

但，什么都没发生。

娇小的少女一动不动。没有倒下，也没有瘫倒，只是站在那里僵住了。宛如一尊少女石像，连一根头发都没动。

H.T.特利斯墨吉斯忒斯觉得，这就像是坏掉的时钟一样。

想必那是如此巨大的冲击吧。

上条当麻。

哪怕是如同印刻般事后追加输入的「老师」身份，

被他拒绝。

青年执事紧咬牙关，发出刺耳的撕裂声。

「噢噢噢噢噢噢。」

不，不只是嘴唇。

撕裂的声音仍在持续。不断地持续着。青年执事的身形开始崩塌。

竖着分为两半。

H.T.特利斯墨吉斯忒斯撕裂自身，向着蓝天咆哮。

将那巨大的断面作为自己的两颚。

他作为超绝者，能力就是为一切物体与现象附加上极致的锋利。

&nbsp;

「姆特·底比斯啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊！！！！！！」

&nbsp;

就这样，专门负责惩罚的超绝者被释放到了世间。

收到号令的超绝者姆特·底比斯，在达成目的之前绝不会停下。

「H.T.特利斯墨吉斯忒斯。」

一个惊诧的声音，朝着情绪激动到将自己身体撕成两半的青年执事说道。恶魔少女看着这个**过于**人域脱离的青年执事，单手叉腰，展开了蝙蝠一般的翅膀，轻轻叹气。

这是超绝者博洛尼魅魔。

她将手臂上赤红的输**液**管拔掉，

「我也自由了，接下来会自己行动，可别因为我不在了就去和『古老善良的玛利亚』吵架啊。要和和睦睦的。别看她那样，母亲大人闹别扭闹得厉害，你要是不主动向她示好，这僵持的气氛可消不掉哦。」

「……」

黏腻的摩擦声接连响起。

青年执事用双手抓住自己的头，将纵向裂开的身体重新按回原位。沉默之中，没有一丝伤痕的超绝者再度恢复完整。

「……了解了。现在姆特·底比斯**已经完成使命**，一般而言，您确实也自由了。那么我想让您去协助处罚任务。」

「那你要去做什么？」

「我会从外面叫同伴过来。一般而言，我们已经惹出事情了。」

低声说到这里，H.T.特利斯墨吉斯忒斯轻咬嘴唇。

之后，他不再出声。

博洛尼魅魔可是偏向上条当麻的救出派。

&nbsp;

（……而这恐怕会成为对伤害了我的爱丽丝的上条当麻最大的攻击。）

&nbsp;

不只是泄露了「桥架结社」机密信息的安娜·施普伦格尔。

上条当麻。

他也是必须消灭的目标。
