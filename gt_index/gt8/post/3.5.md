# 行间四

安娜·施普伦格尔是个坏人。

这一点毋庸置疑。连她本人都承认。

当然，身为坏女人，她一直在以自己的方式努力活下去。她还察觉到了必须阻止的计划的存在，并采取了具体的对抗措施。

即使如此。

在心底某处，她觉得自己的努力**一定不会有结果**。或者说，应该说是放弃了吗？她的祈祷与希望一定会在某个瞬间被击碎，在形势最好的关头被粉碎，而她不知道那个瞬间会在何时到来。既然已经张开双臂全力以赴做了这么多，倒不如说报复迟早要在某处袭来才理所应当。

某种意义上说，

这种自暴自弃，或许才是变幻莫测的安娜·施普伦格尔的本质。

因此，当威胁到她的存在本身的安娜·金斯福德出现时，她畏缩了。她顾不得作为坏女人享受事态，而是意识到了自己有多害怕失去。这不是术式的技术高低的问题，也不是一次能精炼多少魔力的问题，而是她的根基被动摇了。

我想就是这么回事。

到头来，她若不放肆，就无法自由地活下去。

所以，娇小的坏女人越是挣扎，越会让事态变糟。

她对此心知肚明。也就是说，优秀的反派就该在适当地时机优雅地退场。

（……好吧。）

冷。

很冷。

这寒冷不是源于一月份刺骨的冷空气，也不是源于她倒地紧贴着的冰冷地面。而是来自脊梁处更为强烈的冷气，是自内而外侵蚀、肉眼无法得见的死亡触感。

安娜·施普伦格尔缓缓眯起眼睛。

（「桥架结社」那夸张的所谓计划已经向周围交代过了，爱丽丝·异典与上条当麻的联系虽然扭曲，但并未完全断绝……冷静下来想想，我也不是绝对不可或缺的人了呢……事到如今……）

那么，这样也未尝不可。

她已经走了这么多步棋，让一切能推进到下一步，在性价比衡量上可谓是相当优秀。只要上条当麻在魔女们的女神阿拉蒂娅她们的帮助下打破「桥架结社」的野心，一切就结束了，这难道不是很棒的好结局吗？

在安娜·金斯福德揭穿一切之前就此结束，在某种意义上或许也是一种幸运吧。

尽管如此。

话虽如此。

&nbsp;

「你要来做我的对手？」

「……没错。」

&nbsp;

她听到了。

偏偏听到了。

&nbsp;

「你会死的。」

「没错！！」

&nbsp;

她听到了有人绝不接受这理所当然的结局的声音。

她听到了那个如果需要，就会一次又一次地站起来、咬紧牙关对抗这个世界的不合理的少年的声音。

&nbsp;

「真头疼。明明没有特别的理由要和无辜的你战斗。」

「你这么恣意妄为，别说什么都没有！！」

&nbsp;

那并非怒吼。

而是拼命压下想哭的冲动，努力不让自己颤抖的少年的呐喊。

于是，那个倒在地上的坏女人中的坏女人，不禁咬住自己的嘴唇。

（可、恶……我明明都已经做好觉悟了。明明都打定主意直到最后都要作为坏女人笑着死去，连恐惧都彻底驱散了……）

「矮小液体」。

这个出自超乎寻常的爱丽丝·异典之手、专为杀死叛徒而特制的极为特殊的灵装，已经在她的体内发挥出致命的效果。

她注定无力回天了。

她很清楚，可是。

&nbsp;

（……这下，想死都死不了啊。）
