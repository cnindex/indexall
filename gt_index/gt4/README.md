# 简介

**创约·魔法禁书目录4**

作者：镰池和马

## 内容简介

**为了夺回母女之间的牵绊，在洛杉矶极寒之中的上条当麻，奔跑吧！！**

啊咯咯咯……真是冷死了、混蛋！

好不容易从医院病床上挣扎出来的上条当麻，面前竟然是本应温暖但却异常寒冷的洛杉矶？！……而且是全部人口消失的异常状况下的洛杉矶……？！

上条当麻和茵蒂克丝将去共同对抗由安娜率领的R&C超自然公司引起的异常事态。

躲开了敌方魔法师的猛攻后，遇到的唯一的幸存者是位银发褐色的幼小少女，以及她母亲的「踪迹」——

上条当麻继承母女意志之时，就是那个「黑暗」被打破之时！
