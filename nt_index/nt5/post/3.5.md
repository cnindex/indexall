# 行间三

危机管理文件特别项目4431119号。

关于芙罗兰·克洛伊杜尼的安全方面注意事项。

&nbsp;

虽然本业务的主要目的，是将会对学园都市，甚至整个世界的「计划」造成危害之该人物，对世界造成的影响降到最低，但该人物因其性质而难以杀害。因此我们采取将此人当成箱中之猫，尽可能稀释此人对外界影响力的方针。

此方针有需要特别注意的事项。

该人物行动的原动力并非思想，而是好奇心。因此，我们不可让此人对外界产生兴趣。无论如何，用任何方法都无法杀死的该人物一旦对某事产生兴趣，之后无论自己的肉体受到何种破坏，都会朝着成为其目标的物品、状况、场所、人物笔直前进。

虽然有「演算型·冲击扩散性复合材料(Calculate Fortress)」所包围的坚不可摧之箱，然则监于该人物性质，依旧无法称得上牢靠。

最有效果的方法，就是提供完全黑暗、静寂的环境，令该人物失去所有兴趣。

该人物并无好恶概念。

无论外界加诸的是善意或恶意，都会表现出兴趣。

因此，被封于箱中的该人物无论接触到些许的光、波动、声音，都会在感应的瞬间产生强烈的兴趣。一两次的零星状况尚无所谓，但持续一分钟以上的刺激，可说是特别致命且危险。

我们不能给予此人丝毫变化。

只要让此人行动一次，其特有的高速思考就能构想出打破「演算型·冲击扩散性复合材料(Calculate Fortress)」的方法。

而获得能打破「演算型·冲击扩散性复合材料(Calculate Fortress)」方法的该人物，不管运用任何方法，都无法杀害此人或限制其行动。

一旦将获得矛与盾的该人物放入学园都市，应视为与第一级警戒(Code Red)同等的危机。
