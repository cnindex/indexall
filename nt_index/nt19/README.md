## 内容简介

**本应被打倒的学园都市统括理事长变成了美少女，出现在上条面前——？！**

醒来就发全身都被特殊的紧身衣覆盖还无法脱掉的滨面，被卷入了某种犯罪。甚至在街上与一方通行(Accelerator)为敌。在此期间他还背负上了新的麻烦，那就是路边被丢弃的小婴儿。婴儿的手腕上的标签还刻着以L开头的六个字母？愚蠢的混混滨面能否让穿着迷你裙圣诞装的巨乳女友泷壶理后注意到他呢？

与此同时，上条正身处险境。不知为何，他遭到了究极美少女还讨人厌的宿敌亚雷斯塔的反向性骚扰。对方是死敌，但却是无与伦比的美少女，你要怎么做啊刺猬头！
