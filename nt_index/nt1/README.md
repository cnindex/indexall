# 简介

**新约·魔法禁书目录1**

作者：镰池和马

## 内容简介

**没有上条当麻的世界。他用生命所守护的，各种各样的人们的各种各样的安宁日常。**

罗马正教的暗部「神之右席」最后一人，火从俄罗斯引发的第三次世界大战，在上条当麻的活跃下得以终结。他本人也随之消失。

这里是一个没有上条当麻的世界。

魔法侧正在进行重组和改善，信徒们迎来了安息的日子。在科学侧总本山学园都市中，最强超能力者·一方通行(Accelerator)与「黑暗」切断了联系，与最后之作和番外个体一起度过着喧闹却平稳的日常生活。那里也不再有「GROUP」的影子。

前Skill-Out成员、无能力者(Level 0)滨面仕上怀揣在俄罗斯获得的与「黑暗」的交涉材料，与绢旗、泷壶以及归来的麦野共同组成新生「道具」，重新开始活动。

这些从黑暗中毕业的人们已经获得了平静——直到凶恶的「新入生」出现在他们面前为止。
