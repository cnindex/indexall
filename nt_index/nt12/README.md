## 内容简介

**在学园都市矗立的巨大综合商业大楼「类钻」中，上条与魔神圣日耳曼相遇了！！**

上条当麻从全世界的手上守护了欧提努斯。失去了「魔神」之力的她，变成了在上条家寄居的妖精小姐。而且，茵蒂克丝依然幸福地吃着饭。是的，上条恢复了他所渴望的日常生活。

然而，新威胁很快就来了。

——「魔神」行动了。

——在漫长旅途的尽头，终于找到了。

——圣日耳曼。那个名字意味着拥有一切。

作为战场舞台的「类钻」被魔神封锁。卷入最糟糕局面的，是正在购物的「道具」成员们、原本打算帮忙搬东西的滨面仕上，以及学园都市第六位能力者·蓝花悦——的伪装者。

激烈冲突，即将开始。
