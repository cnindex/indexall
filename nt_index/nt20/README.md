## 内容简介

**学园都市与英国清教的全面战争，爆发——**

毫不犹豫地抛弃了自己的根据地·学园都市的亚雷斯塔，开始对魔法大国英国进行总攻。看似非正义的作战中，却不知为何显现出上条、茵蒂克丝、一方通行(Accelerator)、滨面和泷壶的身影——

超越大天使爱华斯力量的大恶魔科隆尊的封印即将被解除。在此之前必须在伦敦抓住他的弱点，但对于被大恶魔附身的萝拉所率领的英国清教来说，这只会被视为科学一方的侵略。

上条正在挑战这场无人希望发生的决战。在如此激烈的情况下，救他于危难之中的，竟然是意想不到的管理员系温柔天然姐姐奥索拉？？？
