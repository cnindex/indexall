**新约·魔法禁书目录8**

## 内容简介

**立于「格雷姆林」顶点的「魔神」欧提努斯，终于行动了。**

在暗中操控的全世界「格雷姆林」。这个科学与魔法融合的组织所引发的各种「威胁」——在夏威夷的恐怖活动、在巴格吉城的「实验」、以及夺取学园都市沉睡中的「不死存在」——背后都有其原因。

「主神之枪(冈格尼尔)」。

为了阻止魔神欧提努斯最终目标神枪的制造，「本应成为魔神的男人」欧雷尔斯伪装成雷神托尔，潜入「格雷姆林」的大本营·船之墓场，并开始调查。

世界崩溃的倒计时已近在眼前。

另一方面，上条当麻早上醒来时发现，蕾薇妮雅（幼小少女）和蕾莎（色气少女）也和他睡在一条被子里。

嗯果然是这样啊！

即使世界危机迫近，上条先生也是如此呢！

第8卷登场！
