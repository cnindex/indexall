# 后记

一本本购买本书的朋友们好久不见。一口气买下所有作品的朋友们，初次见面。

我是镰池和马。

圣人、女武神、魔法结社的首领、前人类桌子、超能力者(Level 5)第一位、第二位、第三位、第四位（……还有第五位？）、雷神魔神及芙罗兰·克洛伊杜尼，这次的故事算得上相当热闹，各位觉得如何？除了身为主要角色的她以外，还有灰姑娘、白色独角仙，这次的主题算是科学魔法共同挑战「人类」这个物种的极限。

另外，雷神托尔的原动力，就系统上来说很接近初期的一方通行(Accelerator)。如果在那个状态下「完全不脱轨地顺利成长」，就会变成那个样子。

某位对话很少，乍看之下会让人觉得「没什么戏份吧？」的角色，其实很意外地在不少地方都跟故事的主线有关，有空的读者可以找找看。

&nbsp;

&nbsp;

非常感谢负责插图的灰村先生和责编三木先生。总之除了战斗不断发生外，每个人都准备了满满的策略，真的让人觉得非常麻烦。非常感谢两位这次也陪我一起度过。

另外也要感谢各位读者。许久没出现以学园都市为舞台的故事，不知各位感觉如何？希望各位之后也能继续陪我一起走下去。

&nbsp;

&nbsp;

那么，这卷就到此为止。

希望各位下次还会翻开下一卷。

至此，请容我先行搁笔。

&nbsp;

有种预感，总觉得灰姑娘似乎能用在很多地方。

<p align="right">镰池和马</p>
