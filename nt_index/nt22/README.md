## 内容简介

**科学的亚雷斯塔VS魔法的科隆尊，终于决出胜负！！！**

大恶魔科隆尊显露了本性。亚雷斯塔倒在了凶刃之下，世界的未来无人知晓。上条当麻和一方通行(Accelerator)挺身对抗……

当以苏格兰为中心的世界崩溃迫在眉睫时，美琴和食蜂所见的激烈冲突结局出乎意料——！！

另一方面，掌控一切的科隆尊也有无法预料的失算。

滨面仕上。为了拯救眼前消失的迪翁·福春，这位真正的「无能力者(Level 0)」与不可预测的诡计大师开始行动。

世界的命运被托付给三位主人公。当「新约」的所有故事交汇时，最终决战就从此开始！！
