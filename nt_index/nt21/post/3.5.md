# 行间三

「安娜·施普伦格尔吗……」

&nbsp;

「黄金」曾经失……一切。

……和布莱斯路之……不同的灾害……发。

「到这个地步……来摧毁我……结社吗？」

不。

严格……安娜·施普伦格尔从来……出现……维斯考特事迹里出……只有信里……名字……已。而马瑟斯正以为能逮住真……时，它却一溜烟从手边……离……

明明真货连一次……出现，却经常……「黄金」的阿喀琉斯之踵……虚构名字。那已非马瑟斯……而是接近一种诅咒的存在……

所以，那并……安娜·施普伦格尔。

马瑟斯带着憎恨这么……哝。

……正确说来——

历史已经证明了一切。看来别西卜和堤丰·赛特对这个贪婪至极的女性似乎都不管用。[^1][^2]

这股无法克制的怨恨。

说不定，和对于威廉·韦恩·维斯考特和亚雷斯塔·克劳利的恨意又有所不同。

[^1]: 译注：别西卜（Beelzebub），意思为「苍蝇王」，非利士人的神，新约圣经中称别西卜为「魔王」，圣经中七大罪的暴食。在这里指的是马瑟斯的诅咒术式。

[^2]: 译注：堤丰（希腊语：Τυφωευς），希腊神话中象征风暴的妖魔巨人。该词在希腊语中译为「暴风」或「冒烟者」。在这里指的是马瑟斯的诅咒术式。
