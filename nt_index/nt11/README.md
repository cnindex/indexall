## 内容简介

**期待已久的最新刊中，新女主角食蜂操祈登场！**

「说起来，我第一次遇到『那个人』也是在那个交叉口吧。」

食蜂操祈第一次与上条当麻相遇，是在掌握许多魔道书的白色修女从魔法世界逃出，从天而降之前的，很久以前的故事。

至今，食蜂操祈仍然记得与那个刺猬头少年之间的回忆。

最开始，她以为是新人搭讪。

期间，被看到了泳装。

期间，用挎包打了他的头。

期间，体验了间接接吻。

最后——

被拯救了生命。

那是她人生中数一数二的「幸福时光」。精神系最强能力者「心理掌握(Mental Out)」的重要「记忆」。

揭开食蜂操祈过去的故事，现在开始。
