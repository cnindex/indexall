# 后记

一本本阅读这套书的读者们，好久不见。

一口气全部买入的读者们，初次见面。

我是镰池和马。

在第十五卷里，科学阵营方面可说是火力全开。七名超能力者(Level 5)、农业大楼、纳米粒子、无人攻击直升机、人造卫星、电脑病毒、Skill-Out……目前为止系列中偶尔出现的科学阵营关键词，在本集全部一次大放送。

这次的主题是「学园都市暗部」与「理智的故事」。除此之外，选择恶之道的一方通行(Accelerator)凶恶表现也是重点。虽说是恶，却绝不是让人感到厌恶的恶。我的目标是希望读者翻完书后能够有种：「啊——好痛快啊」的感觉，不知是否成功了？

说到这个系列中单集所出现的新角色数量，（除了妹妹们(Sisters)以外）我想这卷应该算最多吧。不过这个圈子不会就此扩张，这就是上条当麻与一方通行(Accelerator)的不同之处。

&nbsp;

负责插画的灰村先生、责任编辑三木先生，真的非常感谢你们。这次的故事虽然很复杂，很感谢大家一起陪伴我到最后。

同时也要感谢各位读者。这次的故事虽然偏离了原来的正轨，还是很感谢大家支持。

&nbsp;

那么这卷就到此为止。

希望您还能翻开下一卷。

至此，请容我先行搁笔。

&nbsp;

……那个白色的在不久之后，应该会自称为义贼吧。

<p align="right">镰池和马</p>
