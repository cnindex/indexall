8月31日。

那天，一方通行(Accelerator)在小巷中遇见了一个神秘的少女。她的脸庞似曾相识——

御坂美琴那天在学生宿舍前被一个男生邀请约会。那个男生超帅气——

上条当麻那天在家中感受到不幸的一天即将开始。因为他意识到自己完全没做暑假作业——

8月31日，学园都市的暑假最后一天。他们各自的故事拉开了帷幕——！
