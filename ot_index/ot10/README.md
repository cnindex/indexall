## 内容简介

**「使徒十字」在「大霸星祭」掀起了波澜。那是破坏人们梦想的存在……！当科学与魔法交汇之时，上条当麻的故事就从此开始——！**

为期七天的「大霸星祭」。

那是由运营委员吹寄制理和穿着啦啦队服装的月咏小萌、名门大小姐学校的御坂美琴等，学园都市所有师生齐心协力参与的超大规模活动。

「使徒十字」在「大霸星祭」掀起了波澜。

这个被称作「使徒十字」的存在，会毫不留情地摧毁上条当麻重要之人的梦想……！

上条当麻开始行动。

为了夺回每个人都期待并享受着的「大霸星祭」。

当科学与魔法交汇之时，故事就从此开始——！
