## 内容简介

**科学与魔法的学园喜剧篇终于开始了？当上条当麻和御坂美琴交汇之时，围绕惩罚游戏的故事就从此开始——？！**

九月三十日——学园都市迎来了换季期。

将周围的喧嚣抛之脑后，精英大小姐学校·常盘台中学的超能力者御坂美琴站在音乐厅前的广场上。

她正在等待某人。

然而，「……还没来。」

本应接受惩罚游戏的「那个少年」却始终没有出现。美琴一边叹气，一边抱着薄薄的学生包和小提琴盒子等待着那家伙——

当上条当麻和御坂美琴交汇之时，围绕惩罚游戏的故事就从此开始——？！
