# 序章 恶人们之间的无聊交易

> Key_Shop.

学园都市第十五学区既是最繁华的街道，也是流行的发源地。电视台和各类媒体设施林立的这个学区，也是整个学园都市中地价最昂贵之处。

其中有一幢由高级住宅与企业办公室组成而成的住办大楼。这幢大楼是非常豪华的建筑，会让人觉得与其在这里租屋，还不如干脆一次付清买幢独门独户联排别墅，负担还比较小。

位居学园都市第一位的超能力者(Level 5)的一方通行(Accelerator)，正身处这幢大楼的顶楼。

这里是一名人称「百货公司(Depart)」的男子住处兼办公室。黄昏街景在镶满一整面墙的玻璃窗外延展开来，如果在这里开餐厅，不论菜肴味道好坏，光靠风景想必就能吸引不少客人。

「你不用嫉妒。这里住起来并没有特别舒服，毕竟只不过是『藏身处』之一。只要有人来搜查就得放弃的房子，怎么可能让人放松？」

屋主是个年纪约莫大学生的男子，他坐在椅子上耸着肩膀如此说道。

他对一方通行(Accelerator)并没有抱持警戒。

即使面对红眼白发，单手拄着拐杖却完全令人感觉不出是个弱者，全身散发出只要惹毛了他，就得小心被打成肉酱这种气息的超能力者(Level 5)也一样。

恐怕是因为他早就习惯了。

其实只要稍微思考一下交易的商品内容，就能知道跟「百货公司(Depart)」做买卖的，都不是什么正派人物。

「我不会问发生了什么事。你只要像跟可爱的女服务生点菜一样，轻松说出需要的东西就行。」

即使面对始终沉默不语的一方通行(Accelerator)，「百货公司(Depart)」并未显露出心浮气躁的模样。

「你想要什么商品？逃跑用的车？藏身处的钥匙？还是『换钱』？如果要洗抢来的黑钱，今天的汇率是一比零点八。没多久之前还是一比零点七五，所以现在兑换比较划算哦？你的外貌太显眼了，如果有需要，我可以帮你介绍能变装或整形的地方。」

就像说明主厨推荐的菜肴，他列举出的主要都是逃跑和隐藏行踪时所需的商品。学园都市是座四周被高墙围起的城市，想用「远走高飞」的方法躲过搜查十分困难。因此，准备安全的藏身处或设法隐藏身份混进货运列车，以逃出学园都市（当然就算动这些手脚，成功率还是不高）……就变得很重要。

一方通行(Accelerator)听到这些话之后，依旧保持沉默。

接着，他缓缓环视这间宽敞的房间。

「藏身处啊？你说这里只是你其中一个藏身处，表示这里还兼作样品屋喽？」

「可以算是，这可是我的主力商品。我就是从帮人寻找『藏身处』起家拓展事业的。所以，我不仅对手中的商品十分有信心，也有我的个人坚持。从高级地段的高级大楼到停在第二十一学区山里的露营车，我这里什么『钥匙』都有。你要看看型录吗？」

但是一方通行(Accelerator)完全不感兴趣。

他眼睛看着旁边，视线定住不动。在房间角落，从展现街景的巨大玻璃窗，所倒映出被家具挡住而形成死角的位置上，有某个东西像沙袋一样吊在那里。

「『**那个**』也是你的商品？」

「嗯？**原来你对那个有兴趣啊**。不过很抱歉，那并不是我贩卖的商品。那只是我个人的兴趣。」

「百货公司(Depart)」将目光移向他用锁链吊挂的东西，表情略显苦涩。

就像被朋友发现自己令人意外的兴趣时那种表情。

那是一名大约十五岁的少女。

肌肤白皙的少女只穿着内衣裤，双手被人用枷锁固定住，吊在半空中。

她毫无动静。

全身上下都留有瘀青的少女，连基于羞耻心而缩起身子的力气都没有，只是全身无力地轻轻晃动。因为她还有呼吸声，所以应该还活着，但显得两眼无神而空洞。

一方通行(Accelerator)看着少女说道：

「真是不入流的兴趣。她应该很贵吧？」

「还好啦。啊……喂，你可别弄坏她哦。虽然这个藏身处用完就丢，但处理尸体可是很麻烦的。先不管处理尸体的事，她真的很贵。你要是把她玩死了，至少得付我七百万哦。」

「既然如此，你还把她弄得遍体鳞伤啊。不过你好像没让她去卖啊。」

「就跟你说这只是我的个人兴趣啊，她是用来挨拳头的。如果是要拿来上，这女的根本就不及格。还是你喜欢她那种平胸类型？我真不敢相信。」

一方通行(Accelerator)没有拄着拐杖的那只手抓着一个皮包，他从皮包里拿出一个信封，轻轻放在「百货公司(Depart)」桌上。信封的开口露出十叠一百万一叠的纸币。

看到这些，「百货公司(Depart)」不禁歪着嘴苦笑。

「喂喂。」

「这是预付款。我被指派一份无聊的工作，这会儿火气大得很。我可不保证不会失手杀了人。」

「啧。我先跟你说清楚，光是杀了她就得赔七百万，处理尸体的钱要另付。」

「百货公司(Depart)」的口气听起来略显遗憾。虽说是他的兴趣，但他对她的执着并不深，很轻易就放弃了。他大概是在盘算，只要再买「新的」就好了。

「对了，你对那种小鬼什么地方感兴趣？难道只要是没被其他男人玩烂的女人，你就提不起兴趣？」

「原来如此啊，我好像让你误会了。」

一方通行(Accelerator)随口否认了「百货公司(Depart)」提出的问题。

「我买的不是挂在那边的女人。」

「？」

「**我买的是你**。」

「百货公司(Depart)」一时之间，无法理解一方通行(Accelerator)话中之意。

&nbsp;

喀。

直到他听见自己鼻梁被打碎的声音为止。

&nbsp;

「呜……哇……啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊啊！」

「百货公司(Depart)」因为剧痛而放声惨叫，接着从椅子滚落在地。有一个小包落在他附近。他发现那是一方通行(Accelerator)朝自己脸上丢过来的东西，但他觉得很奇怪。那实在不是一个拄着拐杖的人，用单手就能扔出的威力。这股剧痛的感觉，就像被自动投球机投出的硬球直接朝脸上招呼。

「百货公司(Depart)」单手捂住被打得粉碎，喷出红黑色血液的鼻子，经过一番挣扎终于从地板上站了起来。

「你、你……呜……你、你……你到底想干什么？」

「百货公司(Depart)」拉开昂贵办公桌的抽屉，从里面拿出手枪。不过即使被人拿枪顶着，一方通行(Accelerator)还是无动于衷。他丢出皮包的那只手按着脖子上的项圈，脸上则露出不怀好意的笑容。

然后，他笑道：

「依你的标准……我记得一个人值七百万左右是吧？」

「……！」

不会吧？「百货公司(Depart)」的嘴唇动了。

像是承认了对方最不祥的预感，一方通行(Accelerator)继续说道：

「电话里的那混蛋真是的，居然给我找了这么无聊的工作。反正我也付过钱了，而且现在正好一肚子火——**杀了你应该没关系吧**？」

「百货公司(Depart)」被远超过表面上显现出来的恐惧侵袭，他用发抖的手扣下扳机。但是一方通行(Accelerator)却毫不在乎，他舔着嘴唇冲向「百货公司(Depart)」。

顿时爆出一阵粉身碎骨的声音，和已经超越惨叫的嘶吼声。

&nbsp;

&nbsp;

五分钟后。

用鞋尖轻轻踢了踢浑身是血的肉块，一方通行(Accelerator)百无聊赖地关掉项圈上的开关。他身上毫发无伤。当他解放自己的能力时，就能反射任何攻击。

一方通行(Accelerator)单手拄着拐杖，另一只手拿出手机。他拨打了某个号码，接着将电话放到耳边。

「事情解决了。这种跟狗屎一样的工作太无聊了。啊？需要的东西？我想想，我要派一支回收小队，处理这堆闻了就想吐的肉块，还有……」

说到这里，一方通行(Accelerator)稍事停顿。

他望着仍然吊在角落的少女，接着重新打开项圈上的开关。

他只是轻轻动了动手指，不知为何，远处吊挂少女的锁链就被切断了。

「……我还要一套女人用的衣物。尺寸？不知道。你们随便拿一套能穿的过来就好了。你们这群人没什么品位，就算要求再多也只是白费工夫啦。回收小队也给我派女的过来。要是敢混进一个男的，我就踢爆那家伙的鸟蛋！」

一方通行(Accelerator)把该说的话说完后，就挂断电话。他随便抓起桌上几叠钞票，扔向锁链断掉而倒卧在地的那名少女。

一方通行(Accelerator)连看都没看少女一眼，关掉项圈上的开关。他拄着拐杖走向出口，语气冷淡地说道：

「以后要怎么活都随便你。剩下的人生，成败全看你自己。」

「……」

一直都没有任何反应的少女，终于缓慢地移动脖子，看着一方通行(Accelerator)的背影。她动了动裂伤的嘴唇，仿佛自言自语般轻声问道：

「你是……？」

「我是恶人。」

一方通行(Accelerator)穿过大门，如歌唱般回答道：

「无可救药的恶人。」

&nbsp;

这就是他，或者说是他们的日常生活。

一方通行(Accelerator)、土御门元春、海原光贵、结标淡希。

他们四个人叫做「GROUP」，「GROUP」今天也在驱逐这座城市里的黑暗。
