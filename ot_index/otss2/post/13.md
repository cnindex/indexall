# 第十四章 看门人与入侵者的斗法

> 九月、第三个星期五

这里要再次确认，初春饰利并不是超人。

「？」

放学后在风纪委员(Judgment)活动第一七七支部吃着饼干的少女，似乎突然发现了什么，望向放在铁制办公桌上的笔记本电脑。

（呜？麻烦来了！）

入侵者。

并非针对初春的计算机，也不是针对风纪委员(Judgment)活动第一七七支部。最近接二连三发生了针对管理学园都市所有情报「书库(Bank)」的电子攻击，初春不得不采取对策。进出「书库(Bank)」的情报，全都得先经过风纪委员(Judgment)的大型服务器，绕过一圈之后再前往「书库(Bank)」。之所以会变更为这种设定，都是为了要加强「警备」。

有项信息却无视这种设定，直接前往「书库(Bank)」。

在一般操作之下，这种信息流动是不可能发生的。

是黑客。

而且不是普通黑客。对方并非突破安全系统方面的漏洞，而是从原本没设想到的快捷方式登录。像这种小漏洞，初春事前已经全部堵上了。

也就是说……

&nbsp;

&nbsp;

超能力开发的名门学校，常盘台中学的大小姐御坂美琴，坐在车站的长椅上。她手上的手机正连接着无线网络。

她是学园都市仅有七人的超能力者。

超电磁炮(Railgun)。

这城市里第三位的，电子控制能力中最高等级能力的少女。

美琴直接用食指触碰画面进行许多操作，大量、高速的情报交流正在画面中展开，那已经超乎了她的手指动作。美琴并没有一一注意那快到眼睛都追不上的记号与文字。只要将脑袋中出现的想法转移到机械，计算机就会像余波一样任意进行处理。

美琴试图登录的，是学园都市的「书库(Bank)」。

以往她侵入过那里好几次，到目前为止还没被比美琴强的人阻止过。对方似乎察觉出「也许被入侵了」，但还没发展到整个网络突然被切断，遭到隔离的事态。

（……嗯，对对方而言也是个苦涩的决择吧。如果停止「书库(Bank)」的登录，时间越久，所造成的损害可是比电车紧急停车还要严重。）

哔哔哔哔哔哔哔哔哔哔哔哔哔哔，看着接二连三出现又消失的窗口，美琴轻叹了一口气。

虽然想使出全力赶快解决，但她不想做出破坏自己机器的事。

&nbsp;

&nbsp;

（……嗯。）

初春用眼睛追着试图直接登录「书库(Bank)」的信息，将吃到一半的饼干放回盘子里。

（之前也曾发生过这种事。不过，这次又更厉害了点。）

她看着画面叹了口气。

眼前展开的，是一般计算机操作中绝对不可能发生的现象。

也就是说，对方是使用能力的黑客。

学园都市是超能力者们聚集之处。当然，能办到这种事的能力者多得是。包括有读取用户心理得到密码、操纵电子掌控计算机，甚至还有能直接操纵「情报」本身的人。

光是靠普通的计算机操作无法击退这些家伙。一般用户与黑客的差别，在于前者利用的是系统表面，而后者能读取到背后的情报。但这个「使用能力的家伙」却能更深入内部。

不过，

这里是能力者蠢动的城市，学园都市。

（光这种程度就退缩，根本就无法守护治安。）

重新下定决心的初春，再次确认信息的流动。对方并没有经过初春一开始设定的「最短路径」，也就是说初春的思路并没被掌握。而信息也没有无视防壁就通过，看来情报并没有遭到直接操作。

（这么一来……）

对方恐怕是操纵电子类型的能力者。但因为「电子」系能力者很多，只凭这种情报几乎无法锁定对方身份。

「……」

初春皱起眉来，眼睛追着信息的移动模式。

以这少许的情报为媒介，她开始想象名叫系统的「花朵」。

现在，初春看到的是根部前端。接下来要用想象力补充茎与叶、水与营养的流动等，最后在脑海中拼凑出花朵的全貌。「从各角度想象某机构」这种算式，正是让初春成为一名活跃黑客的真正原因。

如果初春拥有特别的才能，也许她会建构起令人可畏的「只属于自己的现实(Personal Reality)」，发挥强大的力量。

但是，

（……呜……）

初春微咬嘴唇。

从根部前端开始的想象，在进行到茎的部分时突然被弹开。不知是否因为对方利用了高度算式，初春无法想象从「眼前的现象」，连通到「引发出那种状况的『只属于自己的现实(Personal Reality)』」路径。

如果不知道对方的手法，就无法提出对策。

（该怎么办……？）

键盘前的初春，手指微微游移不定。

仿佛筷子不知该夹什么东西的动作，正象征着她的苦恼。

&nbsp;

&nbsp;

「哦，这样啊。」

美琴看着高速展开的画面嘀咕着。

现在，她所进行的是典型的密码解除。

并不是操纵电气的能力者，就能凭借其能力突破所有安全系统。在拥有许多能力者的学园都市里，应对这种不寻常攻击的特殊防壁开发也很进步。

但不论怎么说，拥有能力跟没有能力的人相较下，还是拥有能力的人比较有利。

当然，并非只靠能力就能突破。

没有必要拘泥在这方面。

可以用操纵电气的能力，突破普通计算机难以解除的安全系统，至于对能力用的特殊安全系统则以普通计算机应对。美琴将之有效率地交互使用，入侵各种「目标」。

作业顺利完成。

美琴敲了几个键盘后，突破最后一道安全系统。

（接下来，我看，之前的数据在哪里……咦？）

此时，美琴的动作突然停止。

看着画面的她，只挑动了一下眉毛。

画面上出现的，

&nbsp;

是正以压倒性速度，密码化的「书库(Bank)」内数据群。

&nbsp;

（不会吧……）

从随机切换记号或数字的文字特征看来，那也许是「Ω密码」。那是在学园都市网络上展开，小有规模的绝对密码赛中获得最优秀评价，极为特异的随机数暗号。

（不会吧、不会吧、不会吧？）

这个绝对密码比赛，是人类与计算机进行国际象棋的最高决战般，丝毫没有任何实益的大会。不过，其卓越的成果也相当有名。随机被密码化的数据，就连程序设计者自己也无法解读。那些都是即使利用学园都市的超级计算机也要花上两百年，缺乏实用性，以高难度为优先的奇怪信息。

（是哪里的笨蛋啊？竟然搬出这种东西！）

「Ω密码」麻烦的地方，在于只要一度密码化之后，无论再大或再小的文件，要解读都得花上两百年。因为每个文件都被施以不同的随机数处理，无法像一般方式那样「只要知道解读模式，就能全部套用」。解读一个文件后，下一个文件还是得再花上两百年。

因为整个「书库(Bank)」都被密码化，所以也不知道要找的目标数据在「书库(Bank)」何处。在这种状况下，如果想确实得到数据，就不能只是选择某个数据盗取，而是要跟「书库(Bank)」的保管服务器一样，准备一整个超大容量的数据库，将极端庞大的信息全都转移到那边去……

这么一来的确不好下手。

光是准备那么巨大的服务器，就很容易被发现。就算能事先准备服务器，光是移动「书库(Bank)」庞大的数据要花费多少时间？再怎么说，能管理这么多信息的交流，负责监视的那一方也不简单。

但是，

（……那家伙疯了。就连「书库(Bank)」服务器管理，或保养用的垃圾文件也全被密码化！这么一来大容量服务器本身不就不能用了？）

「书库(Bank)」所使用的器材价值，就连身经百战的大小姐看了都会脸色发青。但是这家伙竟然毫不犹豫就舍弃。这种方法让人忍不住怀疑，直接打开服务器盖子浇水上去，损害说不定还小一点。

（用这么乱来的方法反击，说不定「书库(Bank)」的数据事前已经备份到其他地方去了。朝那一点去进攻，也许可以拿到数据……）

美琴重新望向画面中的大灾难。

对方似乎本领深不可测。感觉上那个人为了击退美琴，即使是紧要关头的备份数据群，也会毫不犹豫地使用。

（黑客最重要的就是不让人发现。）

半晌，美琴不知该如何是好，终于像是放弃似的用一只手抓乱头发。

（……还是照原定计划先撤退吧。一想到要跟这个大笨蛋一起毁灭，就忍不住背脊发寒。）

&nbsp;

&nbsp;

「嗯，今天就这样吧。」

盯着画面的初春饰利低声说道。

入侵者如果一直缠着不放，也许还可以反过来探测对方，但今天这样算是能接受的战果。现在还用不着深入追击，先解析对方的攻击模式，然后应用在防护墙上。

直接操纵电气的黑客们，也许有人会质疑这种「普通手段」是否有效。当然有。自始至终，对方攻击的只是「名为能力的系统内部」，正因为能自由地在例外的部分来去，所以乍看之下才像是「万能」。

既然入侵者具体实行的，只是「接收及送出某种电气情报」，只要找出「例外」之处，填补漏洞，就算是使用「普通手段」，也能充分防止能力者入侵。

（任何事都是学习。对方技术还算可以啦，对我来说也算有好处。）

当心里这么想的初春，将手伸向盘子里的饼干时。

「……初春。」

听到这声音她回过头去，风纪委员(Judgment)的同事白井黑子，站在房间的出入口。「？」看到低着头的白井，初春疑惑地微偏着头。双马尾的同事用拇指指着门的方向，然后低声地说道：

「做得太过火啦。看样子你要被教育一顿了，笨蛋。」
