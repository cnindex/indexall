「呃——根据『入场者编号』的结果，您的指定数字中了头奖！奖品是『北意大利七天五夜的双人旅行』，恭喜中奖！」

那个只能以「不幸」自夸的男人·上条当麻，竟然抽中了海外旅行的双人票。

在这突如其来的幸运面前，上条和茵蒂克丝的情绪达到了顶点。

舞台将转移到漂浮在亚得里亚海的「水都」上的威尼斯本岛！憧憬已久的意大利假期中，还会有令人心跳加速★艳遇发生？！
