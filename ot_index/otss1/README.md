## 内容简介

**当科学与魔法交汇之时，短篇故事就从此开始——！**

上条当麻和吹寄制理的闲聊引发了全班一起举办火锅派对！小萌老师备受困惑？！——《锅与肉与食欲的战争》。

舞台设在伦敦。魔法师少女们编织出的混乱（？）的一天究竟是怎样的？——《英国清教的女子宿舍》。

堕入学园都市暗部的一方通行(Accelerator)。在那里等待着他的是什么？——《枯燥无味的灰色暗巷》。

外貌酷似放电初中妹的她，来到学园都市的理由究竟为何？——《醉酒母亲的目前状况》。

补完「禁书目录」本篇的SS系列登场！
