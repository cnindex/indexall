## 内容简介

**当姐姐大人与「那位先生」交汇之时，白井黑子的故事从此开始？！这是姐姐大人与白井黑子的人气学园动作系列第八弹。**

这里是学园都市中所有女学生都心驰神往的名门女子学校·常盘台中学。当然，入读的学生全都是「大小姐」。

其中一位「大小姐」御坂美琴在体育课后，为了洗去汗水而淋浴时，隔壁传来了一个少女的声音。

白井黑子。她是守护学园都市治安的「风纪委员(Judgment)」，也是拥有空间移动(Teleport)能力的大能力者(Level 4)。她邀请美琴放学后一起去购物。

——黑子漫长的一天就这么开始了。了解姐姐大人·御坂美琴真正面貌的，漫长的一天……

当姐姐大人与「那位先生」交汇之时，白井黑子的故事从此开始？！
