# 简介

**旧约·魔法禁书目录4**

## 内容简介

**「外表」与「内在」互换了？当上条当麻被某种魔法袭击之时，故事就从此开始——！**

从学园城市获得外出许可的上条当麻，和家人一起到海边度假。

而在那里看到的是，变成了茵蒂克丝的母亲、变成了蓝发耳环的茵蒂克丝、变成了史提尔的神裂火织、变成了海边大叔的史提尔、变成了大叔儿子的御坂妹妹、变成了当麻妹妹的御坂美琴？！

这一切、都由「某个」魔法引起。

神秘魔法「天使坠落」似乎以上条当麻为中心展开了——？！

超人气学园动作系列第四弹登场！
