# 后记

一本本阅读这套书的读者们，好久不见。

一口气连读十七本的读者们，初次见面。

我是镰池和马。

这样的后记眼看着快要达到二十篇了。明明应该要习惯，却还是跟本文一样有种朴拙的感觉，这点真是不好意思。

这次的主题是「天择之人」。魔法关键词是「圣人」。水的术式里虽然加入了圣母崇拜等要素，但基本的平台还是圣人之间的互斗。

五和（应该是天草式全体）所放出的「圣人崩坏」，只要回去看第九卷就会知道。这也是很厉害的大绝招。当这个隐藏绝招放出时，魔法阵营的天草式还因此产生组织平衡的崩坏（因此圣人神裂如果不回去当领袖就糟了，希望女教皇归来的建宫他们，也充分发挥了身为策士的能力）。

这卷里出现了许多与系列整体核心相关的情报。在此重新整理一下之前提示的情报会很有趣。之前我在哪个时间点提示了怎样的情报，而这个情报又在哪里被颠覆？仔细调查这点，也许可以掌握今后系列内可能会产生的一小部分发展吧？

&nbsp;

责任编辑三木先生、负责插画的灰村先生，真的非常感谢你们。这卷意外出现很多麻烦的战斗场面描写，真的很不好意思，感谢你们的协助。

同时也要感谢各位读者。感觉上光是这个系列，后台就已经发展得越来越复杂了，很感谢大家的一路支持。

&nbsp;

那么，这卷就到此为止。

希望您下次还能翻开下一卷。

至此，请容我先行搁笔。

&nbsp;

感觉上，五和越来越不像普通女孩子了。

<p align="right">镰池和马</p>
